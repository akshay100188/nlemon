# What real TinyStories text looks like

Measured on 2,000 held-out validation documents, with a known-word set of 19,446 words taken from 100,000 training documents.

These bands are the reference the generated samples are judged against, so the coherence check tests *resemblance to the corpus* rather than anyone's opinion about good prose. Both edges matter: too much repetition is degenerate, too little is suspicious, because real children's stories repeat names and phrases deliberately.
