# Perplexity floors

Measured on 2,000,000 held-out validation tokens with a 8,000-token vocabulary. These are what trivial predictors score; the trained model has to beat them before *learned to speak* means anything.

| baseline | what it knows | NLL | perplexity | nLemon-14 is |
|---|---|---|---|---|
| uniform | nothing at all | 8.9872 | 8,000.00 | **1,464.24x better** |
| unigram | which tokens are common | 5.9659 | 389.91 | **71.36x better** |
| bigram | the previous token only | 3.7332 | 41.81 | **7.65x better** |

**nLemon-14: NLL 1.6981, perplexity 5.4636** over 1,992,060 of these same tokens.

Model and baselines are scored on the **identical token array** here, so the ratios have one numerator and one denominator drawn from the same data. All figures are per-token negative log-likelihood under the same 8,000-token BPE — perplexity is not comparable across tokenizers, so a number from a different vocabulary would not belong in this table.

The model is scored on non-overlapping 256-token windows, so the first token of each window is predicted with no context. That handicaps the model slightly, which makes these ratios conservative.

Generated by `python -m src.baselines`.
